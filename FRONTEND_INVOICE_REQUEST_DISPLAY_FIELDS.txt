FRONTEND DISPLAY: Invoice Request Details - What Fields Are Shown

========================================
OVERVIEW
========================================
This document lists all fields that the frontend displays in the invoice request card/list view. The backend should ensure these fields are included when the `fields` parameter is used.

========================================
INVOICE REQUEST CARD DISPLAY
========================================

1. HEADER SECTION
   ──────────────────────────────────────
   - Short ID Badge:
     * request.invoice_number (priority 1)
     * request.tracking_code (priority 2)
     * request._id.slice(-8) (fallback)
   
   - Created Date:
     * request.createdAt (formatted as relative time, e.g., "2 hours ago")
   
   - Status Badges:
     * request.status (e.g., "IN_PROGRESS", "SUBMITTED", "VERIFIED")
     * request.delivery_status (e.g., "PENDING", "DELIVERED", "CANCELLED")
     * request.has_delivery (shows "Delivery" badge if true)

2. MAIN CONTENT GRID (5 columns)
   ──────────────────────────────────────
   
   Column 1: AWB Number
   - request.tracking_code (priority 1)
   - request.awb_number (priority 2)
   - request.request_id?.tracking_code (fallback)
   - request.request_id?.awb_number (fallback)
   - Shows "N/A" if none found
   
   Column 2: Customer Information
   - request.customer_name (required, bold)
   - request.customer_phone (optional, with phone icon)
   
   Column 3: Receiver Information
   - request.receiver_name (required, bold)
   - request.receiver_company (optional, smaller text)
   - request.receiver_phone (optional, with phone icon)
   
   Column 4: Route Information
   - request.origin_place (shows "Not set" if missing)
   - request.destination_place (shows "Not set" if missing)
   - Displayed with origin → destination arrow
   
   Column 5: Shipment Details
   - request.shipment_type (shows "Document" or "Non-Document" badge)
   - Weight Display (priority order):
     * request.weight
     * request.weight_kg
     * request.verification?.actual_weight
     - Shows "Not set" if none found
   - Total Boxes:
     * request.verification?.number_of_boxes (priority 1)
     * request.number_of_boxes (priority 2)
     * request.verification?.boxes?.length (fallback)
     - Only shown if value exists

3. VERIFICATION FORM (Operations Department Only)
   ──────────────────────────────────────
   - Shown when: userProfile.department.name === 'Operations' AND request.status === 'IN_PROGRESS'
   - Component: VerificationForm
   - Passes: request object (needs full data when opened - fetches separately)

4. FOOTER SECTION
   ──────────────────────────────────────
   - Service Code:
     * request.service_code (formatted/displayed)
   
   - Additional Badges:
     * request.has_delivery (shows "Delivery Required" badge)
     * request.is_leviable (shows "VAT applicable" badge)
   
   - Action Buttons:
     * Generated by renderActionControls(request)
     * Depends on user department and request status

========================================
FIELD PRIORITY FOR DISPLAY
========================================

AWB Number (in order):
1. request.tracking_code
2. request.awb_number
3. request.request_id?.tracking_code
4. request.request_id?.awb_number

Weight Display (in order):
1. request.weight
2. request.weight_kg
3. request.verification?.actual_weight

Total Boxes (in order):
1. request.verification?.number_of_boxes
2. request.number_of_boxes
3. request.verification?.boxes?.length

Short ID (in order):
1. request.invoice_number
2. request.tracking_code
3. request._id.slice(-8)

========================================
REQUIRED FIELDS FOR LIST VIEW
========================================

Core Fields (Always Required):
- _id (for React key and identification)
- invoice_number (for short ID display)
- tracking_code (for AWB and short ID fallback)
- status (for status badge)
- delivery_status (for delivery status badge)
- createdAt (for "Created X ago" display)
- customer_name (required in card)
- receiver_name (required in card)
- origin_place (for route display)
- destination_place (for route display)
- service_code (for service badge)
- has_delivery (for delivery badge)
- is_leviable (for VAT badge)

Optional Fields (Displayed if Available):
- awb_number (AWB fallback)
- customer_phone (shown with icon if exists)
- receiver_company (shown if exists)
- receiver_phone (shown with icon if exists)
- weight (for weight display)
- weight_kg (for weight display)
- number_of_boxes (for boxes count)
- shipment_type (for Document/Non-Document badge)
- invoice_id (for checking if invoice generated)

Nested Fields (Displayed if Available):
- verification.actual_weight (weight fallback)
- verification.number_of_boxes (boxes count priority 1)
- verification.boxes.length (boxes count fallback)
- request_id.tracking_code (AWB fallback)
- request_id.awb_number (AWB fallback)
- request_id.status (for reference)
- request_id._id (for reference)

========================================
CONDITIONAL DISPLAYS
========================================

1. Invoice Generated Indicator
   - Condition: request.invoice_id || request.invoice_number exists
   - Visual: Green border and background tint on card

2. Verification Form
   - Condition: Operations department AND status === 'IN_PROGRESS'
   - Note: Form fetches full data separately when opened

3. Delivery Badge
   - Condition: request.has_delivery === true
   - Display: "Delivery Required" badge

4. VAT Badge
   - Condition: request.is_leviable === true
   - Display: "VAT applicable" badge

5. Customer Phone
   - Condition: request.customer_phone exists
   - Display: Phone icon + number

6. Receiver Company
   - Condition: request.receiver_company exists
   - Display: Smaller text below receiver name

7. Receiver Phone
   - Condition: request.receiver_phone exists
   - Display: Phone icon + number

8. Total Boxes
   - Condition: Any of the boxes fields has a value
   - Display: "Boxes: X"

========================================
SUMMARY
========================================

The frontend displays:
- 20+ fields in the main card view
- Uses fallback logic for AWB, weight, and boxes
- Shows conditional badges based on flags
- Displays verification form for Operations department
- Uses minimal data for list view, fetches full data when needed

The backend should ensure all fields listed in "REQUIRED FIELDS FOR LIST VIEW" are included when the `fields` parameter is provided, plus any fields needed for invoice generation functionality.
